## 进展明细

### Argo 部署基础设施

- **变更**：新增项目根目录 `Dockerfile`、`.dockerignore`，以及 `argo/dlp-affinity-train.yaml`、`argo/dlp-affinity-predict.yaml`
- **原因**：在阿里云 Argo 集群执行 DLP-Affinity 训练微调与预测，需要可复现运行环境与可参数化工作流模板
- **关键文件**：`Dockerfile`、`.dockerignore`、`argo/dlp-affinity-train.yaml`、`argo/dlp-affinity-predict.yaml`
- **结果**：镜像基于 PyTorch CUDA runtime，挂载 PVC `/mnt/data`；训练模板调用 `train.py`，预测模板调用 `predict.py`；产物路径经 outputs.parameters 回传

### 对齐国内镜像源与阿里云 ACS GPU 配置

- **变更**：`Dockerfile` 改为 biocloud 国内基础镜像 + 阿里云 apt/pip + HF 镜像；Argo 模板采用 `pvc-nas`/`/mnt`、ACS GPU labels 与 A10 资源规格
- **原因**：与 Enzyme_designer / 阿里云 Argo 集群既有投递方式一致，避免境外拉镜像与依赖失败
- **关键文件**：`Dockerfile`、`argo/dlp-affinity-train.yaml`、`argo/dlp-affinity-predict.yaml`

### 训练 Workflow exit code 1 排查与修复

- **现象**：`dlp-affinity-train-*` 三次重试均约 21s 失败；ACS/ECI 上 `kubectl logs` 为空
- **根因**：7KMG DMS CSV 列为 `antibody_seq/antigen_seq/escape_fraction`，`AffinityDataset` 默认只读 `seq_ab/seq_ag/kd`，加载即 KeyError
- **变更**：`data/dataset.py` / `predict.py` 兼容 DMS 列名；Argo 日志写入 NAS，并优先跑 `${WORK_ROOT}/release_package`
- **关键文件**：`release_package/data/dataset.py`、`release_package/predict.py`、`release_package/train.py`、`argo/dlp-affinity-train.yaml`、`argo/dlp-affinity-predict.yaml`
- **结果**：本地加载 1556 条样本成功；重跑前需把 `release_package` 同步到 NAS 或重建镜像

### ESM2 从 NAS 本地目录加载（150M）

- **变更**：`train.py` 增加 `--esm_model`；`infer_esm_hidden_dim` 对 150M 设 `hidden_dim=640`；Argo 参数 `esm-model-path` 默认 `/mnt/nas1/liubo/models/esm2_t30_150M_UR50D`
- **原因**：集群内从 NAS 加载 HF 格式 ESM，避免默认 3B 与境外下载
- **关键文件**：`release_package/train.py`、`release_package/configs/config.py`、`argo/dlp-affinity-train.yaml`、`argo/dlp-affinity-train.submit.sh`
- **结果**：训练默认走 NAS 150M 基座；`esm-checkpoint` 仍为可选微调 `.pt`

### 修复 transformers 禁用 torch 2.3.1

- **现象**：`AutoModel requires the PyTorch library but it was not found`；日志：`Disabling PyTorch because PyTorch >= 2.4 is required but found 2.3.1`
- **根因**：镜像 `pip install transformers>=4.25.0` 拉到过新版本（≥4.52），与基础镜像 `torch 2.3.1` 不兼容
- **变更**：钉死 `transformers==4.46.3`、`accelerate==0.34.2`；训练脚本启动时校验并必要时 `pip install` 降级
- **关键文件**：`release_package/requirements.txt`、`Dockerfile`、`argo/dlp-affinity-train.yaml`
- **结果**：无需立刻重建镜像即可重跑；重建镜像后同样锁定该版本

### 预测失败二次排查（dlp-affinity-predict-8fbtw）

- **现象**：软链 `dlp-affinity-train -> dlp-affinity-train_20260706_140852` 后 checkpoint 可读，仍 exit 1
- **日志**：`Unexpected key(s) in state_dict: "esm_encoder._model...."`（约 30 层 ESM 权重）
- **根因**：`ESM2Encoder` 懒加载，预测构建时 `_model is None`，未注册子模块，无法匹配训练 checkpoint 中的 `esm_encoder._model.*`

- **相关文件**：`release_package/predict.py`、`release_package/models/esm_encoder.py`
- **结果**：本地已修；**须同步 NAS** `release_package` 后重新投递预测
